🏥 AI Powered Health Assistance App

An Android application built using Jetpack Compose and Kotlin, designed to help users track their health, get illness predictions based on symptoms, set medicine reminders, and chat with an AI-powered health assistant. The app aims to make healthcare easily accessible and assist users in daily wellbeing monitoring.

✨ Features

🔐 Firebase Authentication (Login & Signup)

🤖 AI Health Chatbot using Gemini API

🩺 Symptom-based disease prediction

💊 Medication tracking with reminders

🚰 Dehydration / Water intake reminders

⏰ General health alarms

📍 Location-based features (optional future enhancement)

📄 Store user details like name, age, weight, height, gender

🧩 Modern MVVM architecture

🛠 Hilt dependency injection

🧭 Single activity navigation with multiple composable screens

📲 Clean UI using Jetpack Compose

🏗 Tech Stack
Category	Technology
Language	Kotlin
UI Framework	Jetpack Compose
Architecture	MVVM
Backend	Firebase
AI Model	Google Gemini API
Dependency Injection	Hilt
State Management	StateFlow / ViewModel
Notifications & Scheduling	WorkManager / AlarmManager
Build Tool	Gradle

📌 Key Modules

authentication – Login, Register, Firebase integration

ai_chat – Gemini-powered chatbot UI

symptom_selection – Add/remove up to 10 symptoms with chips

prediction – Predict illness based on symptoms

reminder – Medication & hydration alert setup

profile – Basic user info storage
